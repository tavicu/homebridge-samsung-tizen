# Introduction

Homebridge Samsung Tizen is a plugin for [Homebridge](https://github.com/homebridge/homebridge) that controls Samsung TVs running Tizen OS **(2017 and later)** from the Apple Home app.

The main focus of the plugin is that basic functionality works on your local network, with no internet connection required. [SmartThings](/smartthings/index.md) is optional. It is an add-on that brings extra features, not something the plugin depends on.

The plugin has its own interface in Homebridge UI, which helps you add devices and configure everything. This documentation walks through installation, pairing, and every setting. Start with [Getting started](/installation/index.md).

::: tip Upgrading from version 5?
Version 6 is a full rewrite. Your TVs stay in Home, but a few settings changed and SmartThings has to be authorized again. Read [Upgrading from version 5](/extra/upgrading.md) first.
:::

If something does not work, check the [common issues](/troubleshooting/common-issues.md) page. When you open a GitHub issue, follow [how to open a new issue](/troubleshooting/open-new-issue.md) so the report includes the details needed to help.
